**核心指令**：
- 识别影像中田块的整体边界（相对坐标 0-1）
- 估计小区的行列数
- 必须输出纯 JSON 格式，不要包含 JSON 以外的解释文本或 markdown 代码块

**必须输出的字段**：

1. **field_bbox**: 田块边界在影像中的相对坐标 [left, top, right, bottom]
   - left: 左边缘 X 坐标（0-1）
   - top: 上边缘 Y 坐标（0-1）
   - right: 右边缘 X 坐标（0-1）
   - bottom: 下边缘 Y 坐标（0-1）

2. **n_rows**: 总行数（正整数）
3. **n_cols**: 总列数（正整数）

**推断规则**：
- 仔细观察影像中的田块、田埂、边界线
- 田块边界应该是包含所有小区的最小矩形
- 行列数应该与示例区域的大小相匹配
- 如果无法确定精确值，给出最佳估计

**输出示例**：
{
  "field_bbox": [0.1, 0.1, 0.9, 0.8],
  "n_rows": 10,
  "n_cols": 15
}

**重要**：
- 只输出上述 JSON，不要输出 plots 数组
- 不要输出 polygon 或 bbox 列表
- 坐标是相对值（0-1），不是像素值
- 如果无法分析，返回 {"error": "无法识别田块布局"}
